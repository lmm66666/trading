# Model 规范

本目录只保留财报及旧行情迁移/回滚模型；技术策略运行时模型位于 `internal/infrastructure/mysql/`。新增生产模型遵循以下规则：

1. 时间戳使用 UTC `time.Time`，MySQL 精度为 `DATETIME(6)`；进入持久化边界前统一 `UTC().Truncate(time.Microsecond)`。
2. 只有“交易日”这类不表示瞬时时间的字段使用独立 date-only 值，不用带时区的时间戳表达，也不新增自由格式日期字符串。
3. 每个模型显式实现 `TableName()`，表名使用 `t_` 前缀和 snake_case。
4. 每张表一个 Go 文件；索引、唯一性、版本可见区间和字段精度写在模型中，不依赖隐式默认值。
5. 需要可变业务记录时显式保留创建、更新时间等审计字段；版本化行情使用有效版本区间和发布记录，不使用软删除模拟历史版本。
6. 金额与价格使用项目定义的定点整数类型，不以 `float64` 持久化；外部财报兼容字段除外。

旧 `StockKlineDaily`、`StockKlineWeekly` 的日期字符串仅供迁移读取，不得作为新代码示例。正常服务启动不会迁移或访问对应旧表。
