# 行情领域设计

| 属性 | 内容 |

| 状态 | 当前有效 |

| 最后更新 | 2026-09-14 |

## 1. 职责与非职责

本模块定义与数据源、数据库和传输协议无关的行情语言：证券身份、周期、价格/金额、Bar、复权因子、公司行动、Dataset、跨周期对齐和周线聚合。它负责在领域边界拒绝不完整、矛盾或所有权不一致的数据。

本模块不请求外部行情、不选择最新版本、不持久化数据、不实现指标、策略或撮合，也不推断具体交易日历。

## 2. 对外能力与使用者

- `InstrumentID` 解析和校验完整证券身份，并区分股票、期货和主力连续序列。
- `NewDataset` 把同证券、同周期、同版本的 Bar 构造成按收盘时间稳定有序的不可变视图。
- `AdjustedPrice` 按时间选择已知复权因子；缺失或非法因子返回无效结果。
- `AlignAsOf` 把主周期 Bar 映射到当时已经确认的辅助周期 Bar，不允许读取未来值。
- `AggregateWeekly` 从日线确定性生成 ISO 周 Bar，并检测成交量和成交额溢出。

指标、策略、回测、应用服务和基础设施适配器共同使用这些领域对象。

## 3. 依赖和边界

模块只依赖 Go 标准库。外部 JSON、GORM Model、数据库字符串枚举和来源特有字段必须由适配器解析后再构造领域对象。

基础设施可以把领域对象映射为存储模型，但不得把数据库默认值当作领域校验。上层对数据版本的可见性选择不属于本模块。

## 4. 核心模型与不变量

### 4.1 证券身份

- 身份始终包含交易所和代码；六位代码不是完整身份。
- 股票交易所为 SSE、SZSE、BSE；期货交易所与品种必须属于显式支持集合。
- `.MAIN` 表示上游定义的主力连续序列，不表示可交割合约，不携带系统自行换月或复权的含义。

### 4.2 数值和周期

- `Price` 与 `Money` 是缩放 10000 的有符号整数，领域计算不得先退化为持久化浮点值。
- `DataVersion` 是无符号版本身份；非迁移聚合场景的可消费数据版本必须为正数。
- `Timeframe` 目前承载日、周和月枚举；具体用例可以只支持其中子集。

### 4.3 Bar 与 Dataset

- Bar 的证券、周期和版本必须与 Dataset 元数据一致。
- 开盘和收盘时间使用 UTC，开盘早于收盘；Bar 按收盘时间严格递增，重复时间非法。
- OHLC 必须自洽，成交量和成交额不得为负，交易状态必须是有效枚举。
- Dataset 构造时排序并防御性复制；调用者不能通过输入或返回切片修改内部数据。

### 4.4 周线

- 同一 ISO 年/周的日线聚合为一根周线：首日开盘、区间最高/最低、末日收盘、成交量和成交额求和。
- 周线收盘时间等于该周最后一根已包含日线的收盘时间。
- `AggregateWeekly` 是纯聚合能力；“只发布已结束 ISO 周”由行情采集用例结合已观测数据实施。生产发布不得把仍可能变化的当前周保存为完成周线。

### 4.5 复权、公司行动和对齐

- 复权因子按生效时间使用最近已知值，缺失、非正、NaN 或无穷值不能产生有效复权价。
- 公司行动必须有稳定 ID、证券、除权时间、类型和数据版本；具体账户影响由回测模块处理。
- 辅助周期只能使用主 Bar 截止时已经收盘的最新 Bar；没有已确认辅助值时跳过对应主 Bar 映射。

## 5. 主要流程

```text
适配器解析外部数据
  → 构造并校验 Bar / Factor / Action
  → NewDataset 排序、校验、复制
  → 指标或策略按固定版本消费
```

周线生成遵循“先得到合法日线 Dataset，再按 ISO 周聚合”的顺序。跨周期策略先分别构造合法 Dataset，再通过 `AlignAsOf` 建立只向历史看的映射。

## 6. 失败和一致性语义

- 非法身份、元数据、Bar 或 Dataset 返回稳定领域错误，不返回部分 Dataset。
- 周线成交量或成交额溢出返回 `ErrBarOverflow`，不返回截断数值。
- 复权缺因子使用 `(value, false)` 表达无效，不以零值伪装价格。
- 所有构造与聚合操作不修改调用者输入。

## 7. 性能与安全约束

- Dataset 构造包含排序，调用者应在批量加载边界控制单证券历史长度。
- 对齐按时间顺序处理，不得为每根 Bar 回查仓储。
- 整数求和和价格转换必须检查溢出；无效外部数值不得进入领域。

## 8. 测试与验收证据

关键证据覆盖身份分类、Dataset 排序/重复/所有权、复权缺失、禁止未来对齐、ISO 跨年周线、停牌状态和算术溢出。

