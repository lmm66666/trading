# 宏观流动性分析流程

> 本文档指导如何执行独立的宏观流动性分析。本流程仅评估宏观资金面，不扫描任何个股信号。执行前请先阅读 `api_reference.md` 了解 API 速查表。

## 分析模式

| 模式 | 触发条件 | 核心任务 |
|------|----------|----------|
| 宏观流动性 | 用户提到"宏观"、"流动性"、"经济"、"宏观分析" | 评估宏观货币财政政策对市场流动性的影响，生成独立报告 |

## 执行步骤

### 步骤 1：采集核心指标

按以下优先级采集宏观数据。**API 已支持的优先调用 API，缺失的通过外部数据源补充。** 具体接口见 `api_reference.md`。

| 数据项 | 数据源 | 状态 |
|--------|--------|------|
| USD/CNY（在岸） | `GET /api/macro/exchange-rate?code=USDCNY` | API 已支持 |
| USD/CNH（离岸） | `GET /api/macro/exchange-rate?code=USDCNH` | API 已支持 |
| 美元指数 DINIW | `GET /api/macro/exchange-rate?code=DINIW` | API 已支持 |
| Shibor 隔夜（DR007 近似参考） | `GET /api/macro/shibor?period=001` | API 已支持 |
| 中国 10Y 国债收益率 | 外部：中国债券信息网 / Wind | **接口待补充** |
| 美国 10Y 国债收益率 | 外部：FRED / Wind | **接口待补充** |
| DR007 加权平均利率 | 外部：中国货币网 / Wind | **接口待补充** |
| 7 天逆回购利率 | 外部：央行官网 | **接口待补充**，当前静态值约 1.50% |
| 北向资金（5日/20日净流入） | 外部：港交所披露易 / 东方财富 | **接口待补充** |
| 社融存量同比增速 | 外部：央行官网 / Wind | **接口待补充** |
| 近 6 个月降准降息记录 | 外部：央行官网 | **接口待补充** |
| 专项债发行进度 | 外部：财政部官网 / Wind | **接口待补充** |

### 步骤 2：评分（引用 scoring_liquidity.md）

读取 `scoring_liquidity.md` 获取评分细则，按四个维度计算加权得分。

### 步骤 3：现状原因分析

完成打分后，回答："为什么当前流动性处于这个状态？" 从以下四类驱动力解释成因：

| 驱动类别 | 需阐明的内容 |
|----------|--------------|
| 经济基本面 | PMI、社零、固投、地产、CPI/PPI 如何驱动当前货币立场 |
| 央行操作 | 近 30 日 OMO/MLF/降准/再贷款工具的净投放与回笼 |
| 外部约束 | 美联储立场、美元指数、中美利差、全球避险情绪对国内宽松空间的压制 |
| 财政与信贷 | 政府债节奏、财政存款、信贷需求强弱、企业/居民加杠杆意愿 |

**输出要求**：明确指出当前流动性的核心矛盾与主导方，不允许只罗列指标。

### 步骤 4：未来影响因素分析

按 1 个月内 / 1-3 个月 / 3-6 个月 三个时间维度，列出关键事件与数据，并：

1. 列出至少 3 个上行风险（流动性可能超预期宽松）
2. 列出至少 3 个下行风险（流动性可能超预期收紧）
3. 给出基准 / 乐观 / 悲观三情景推演，标注评分调整幅度与概率

### 步骤 5：输出报告

生成标准化 markdown 报告，输出到 `./docs/analysis/economy/`。

| 文件名格式 | 示例 |
|------------|------|
| `{日期}-宏观流动性分析.md` | `2026-05-12-宏观流动性分析.md` |

## 六、未来流动性影响因素

### 6.1 关键事件与数据时间表

| 时间维度 | 关键事件/数据 | 可能影响 |
|----------|--------------|----------|
| 1 个月内 | {例：MLF 到期续作规模、LPR 报价、季度末资金面} | {若缩量续作则边际收紧，若降息则进一步宽松} |
| 1-3 个月 | {例：美联储议息会议、国内政治局会议、三季度GDP} | {若美联储降息则汇率约束缓解，国内政策空间打开} |
| 3-6 个月 | {例：年末资金需求高峰、中央经济工作会议、美国大选后政策} | {年末财政支出加码对冲资金紧张；海外政策不确定性落地} |

### 6.2 上行风险（流动性可能超预期宽松）

1. {例：经济数据超预期走弱触发加速降准降息}
2. {例：美联储进入明确降息周期，中美利差倒挂快速收窄}
3. {例：财政政策大幅加码（特别国债、专项债提前发行）}

### 6.3 下行风险（流动性可能超预期收紧）

1. {例：通胀反弹或资产泡沫担忧导致央行转向谨慎}
2. {例：汇率快速贬值突破关键关口触发离岸流动性收紧}
3. {例：海外金融危机或地缘冲突引发全球美元流动性紧缩}

### 6.4 情景推演

| 悲观情景 | {政策收紧 + 外部冲击} | {流动性收紧，评分下调 10-20 分} | {高/中/低} |

## 风险提示

1. 宏观评分基于公开市场数据，政策突变（如突发降准/加息）可能导致评分迅速失效
2. 单一宏观指标异常波动可能是短期噪音，需结合多个维度综合判断
3. 外部冲击（地缘政治、全球金融危机等）可能颠覆既有流动性趋势
4. 本评分不构成投资建议，仅作为仓位管理与择时的参考框架

## 注意事项

1. **评分客观**：评分需有明确依据，原因描述具体，避免模糊表述
2. **前瞻判断**：未来影响因素必须结合当前已知日历事件与经济周期位置，不得照搬通用模板
3. **独立报告**：宏观流动性报告不包含任何个股内容，不与个股评分合并
4. **增量分析**：如 `./docs/analysis/economy/` 下已有同日期报告，询问用户是否覆盖
