# 手动保存的行情看板

## 范围与使用条件
个人行情研究，沿用自选上限 100；保守支持最多 20 个命名看板，每看板最多 16 个技术指标和 1 个固定行情叠加。请求由切股、修改参数或历史分页触发，不轮询。首版沿用浏览器 localStorage，不增加账户、跨设备同步或数据库表。用户已于本会话确认方案并要求执行，后提供有效仓库路径；本记录将该确认落实到现有代码。

## 需求
- BOARD-001 自选列表：紧凑行、名称代码与报价对齐、明确选中态、筛选、涨跌幅排序、添加入口、宽度调整与收起。默认顺序沿用服务端添加顺序，报价更新不主动重排。
- BOARD-002 配色：红涨绿跌，MA5 #FDE68A、MA20 #60A5FA、MA60 #C084FC，主图价格线使用细线；图例提供原始价格。
- BOARD-003 主图百分比：固定共同基准日的各自收盘价，(价格/基准价-1)*100；OHLC 和均线统一使用股票基准价；副图保持原单位。基准不随分页或平移改变。
- BOARD-004 单个固定叠加：支持已有八个期货连续品种，油价为 INE:SC.MAIN。股票切换只替换主标的和其指标，固定关联行情不变；使用主图版本、时间范围，缺失不补值。首版只支持一个固定行情，均线不计入此限制。
- BOARD-005 命名看板：新建、保存、另存为、重命名、删除、恢复已保存；配置包含默认股票、周期、复权、指标参数、分区布局、观察根数和关联行情。手动写入，保存失败保留编辑且不显示成功；最多20个，最后一个不可删除。
- BOARD-006 状态与恢复：保存配置与当前草稿分离；切股不算配置变更，设置默认股票需显式操作；重进恢复上次选定看板与默认股票，显式 URL 股票优先；未保存切看板提示保存/放弃/取消，刷新关闭使用 beforeunload 提示，切换工作台页签保留内存草稿。
- BOARD-007 标准差：STD(period)，总体标准差，输入为主标的当前价格视图的收盘价，默认20；周期1–500，预热不足不输出。在后端完整历史计算后截页。MACD、STD、成交量独立分区，配置参数可编辑。

## 非目标与兼容
不扩展期货搜索和自选目录、不接新行情来源、不改数据库、不改变策略、回测、已有指标公式。旧 URL 和自选数据保留；此前没有持久化指标配置，无需迁移旧配置。不自动保存修改、不引入版本历史或多图窗口。具体测试映射见 verification.md。
