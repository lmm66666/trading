想先理解图表页的数据从哪里来、怎样翻页，请读 [图表查询](workflows/chart-query.md)。本文保留前端状态、组件与 API 客户端契约。

## 1. 职责与非职责

本模块是 React 行情工作台，采用 TV 风格三段布局（顶栏：品牌、图表/扫描/回测 tabs、右上角搜索；左侧自选面板；主工作区），负责证券搜索、日/周和 RAW/QFQ 切换、K 线与成交量展示、指标选择、固定版本向前分页、图表缩放边界与历史自动加载、服务端自选清单管理、URL 状态和用户可理解的加载/错误反馈；并提供策略扫描与回测两个视图：扫描为顶部条件与下方结果工作区，回测为左配置右结果双栏工作区（含日期范围选择器）、策略目录选择与参数输入、扫描/回测任务的创建与轮询跟踪、扫描入选名单与失败明细分页、回测摘要/权益曲线/订单成交展示。

前端不计算服务端技术指标或策略信号、不推断证券交易所、不选择不同页的最新行情版本、不保存历史任务列表（每类视图仅恢复最近一个任务标识；扫描额外保存一份草稿和最近提交上下文，不保存结果表）。

## 2. 组件和边界

- `App` 采用两行网格布局（顶栏 48px 跨双列 + 自选面板默认 260px（桌面220–360px可调、可收起） + 主工作区 1fr），管理已选证券、周期、复权视图、视图切换（图表/扫描/回测，URL `tab` 白名单）、移动端搜索浮层与自选抽屉开关，并同步 URL；持有扫描/回测任务标识（localStorage `wb.scan_run_id`、`wb.backtest_run_id`）与自选状态（挂载时 `listWatchlist`；`toggleWatch` 在列→移除、不在→添加，成功以服务端返回的完整列表替换，失败保留原列表并提示）。
- `InstrumentSearch` 是嵌入顶栏右上角的紧凑 combobox（移动端由 CSS 切换为全屏浮层；回测面板内嵌第二个实例用于选择回测标的），对输入做 220ms 防抖，支持键盘导航，取消过期请求并返回完整证券身份；`/` 全局快捷键聚焦顶栏搜索（输入态除外），Escape 收起，选中后清空输入。
- `WatchlistPanel` 展示自选行（名称/代码 + 最新价与涨跌幅，红涨绿跌，null 显示 —）、当前证券高亮、悬停移除、手动刷新与空/载/错三态；行点击进入图表视图。
- `ChartWorkspace` 管理查询世代、固定版本分页、指标列表和页面状态；图表头部提供 ★ 收藏开关（`watched`/`onToggleWatch`，与自选列表一致）。
- `FinancialChart` 把 Bar 和指标 Series 映射到主图/副图；按容器宽度换算可见 K 线数量上下限（桌面 15–400 根、容器 <768px 移动 10–160 根）为 `barSpacing` 边界并随容器尺寸重算，可见范围左缘接近已加载数据左端（阈值 12 根）且仍有历史时自动请求更早一页。
- `IndicatorManager` 管理服务端支持的预设与参数编辑/排序/移除，支持双价格 Z-score；参数和2000成本预算在前端先校验，不在浏览器重新计算技术指标。
- `features/strategy` 提供共享的策略表单（目录驱动的参数输入与 min/max/integer 校验）、日期范围选择器 `RangePicker`（受控 `from`/`to`，快捷预设与双月历区间点选，仅在确定/清除时显式回写；弹层经 portal 渲染到 `body` 并按触发器 fixed 定位，避免被滚动列裁剪；弹层按实际 top 限制剩余视口高度并允许内部滚动，窄屏预设列不收缩）、任务轮询 hook（2 秒固定间隔、终态停止、连续 3 次网络错误停止）和任务状态条（状态徽标、取消入口）。轮询可通过 active 暂停并手动 retry；扫描/回测启用结构化错误分类，明确 404/NOT_FOUND 立即停止并通知面板清理失效引用，其余非重试业务错误立即停止。
- `features/scan` 提供顶部条件与下方结果工作区：`ScanForm` 管理中文策略/参数、日期直接输入与范围日历、明确的全部交易所选项及折叠参数/高级设置；`ScanPanel` 协调草稿、当前任务和候选结果；`scanPreferences` 只保存有界本地偏好并验证恢复值；目录加载失败可显式重试；`ScanResults` 在新快照首屏成功后原子替换已展示结果，并用固定快照 key 续页。提交契约不变。
- `features/backtest` 提供顶部条件、下方报告的单标的回测工作区；BacktestForm 管理输入和校验，BacktestPanel 分离草稿、当前任务和已展示报告，BacktestReport 组合冻结上下文、四个主指标、权益曲线和按需加载的成交/订单标签页。
- `api/client` 定义前端契约 DTO、统一解析响应 Envelope；`ApiError` 保留 HTTP 状态和业务标识，`ConnectivityError` 表示传输/解析故障，调用方按场景提供可读反馈；集中承载金额缩放换算（×10000）纯函数。

后端契约见 [API 文档](../standards/http-api.md)。

## 3. 核心状态与不变量

- URL 只接受合法的完整 A 股身份、DAY/WEEK 和 RAW/QFQ；非法值回落到安全默认值。
- 选择证券或改变周期/复权视图时创建新的查询世代，清空旧结果并取消首屏/分页请求。
- 首次图表请求使用服务端解析的正 `data_version`；加载更早数据必须传回同一版本和 `next_before`。
- 旧页只有证券、周期、价格视图和版本都与当前结果一致时才允许合并。
- Bar 按 close_time 去重并升序；指标按稳定 key 合并，点按 time 去重并升序。
- 全部 API 客户端调用不做 dev mock 回退，无后端时统一呈现错误态（自选变更成功以服务端返回的完整列表替换本地状态，失败保留原列表）；报价仅在加载与手动刷新时读取，不做实时推送。
- 价格轴（主图与各指标副图）始终自动缩放以适配可见 K 线与叠加指标；可见 K 线数量按设备上下限换算为 `barSpacing` 边界（`maxBarSpacing = 容器宽 / 最少根数`，`minBarSpacing = max(容器宽 / 最多根数, 3px)`），超出边界的缩放由图表库自动钳制，容器尺寸变化时重算。
- 历史自动加载复用 `before` 游标、`has_more` 与查询世代守卫；加载中不重复触发，失败保留已展示数据并可重试。
- 已取消或旧世代响应不得修改 UI，即使网络层稍后完成。
- loading、ready、error 和“空行情”是不同状态；分页失败保留已经展示的数据并显示提示。
- 任务轮询到达终态（含 PARTIAL_SUCCEEDED）即停止；连续 3 次网络错误停止轮询；面板卸载即停，任务在后端继续。扫描/回测有任务 ID 且尚无响应时显示恢复中，不显示未运行空态；明确任务不存在时只清除对应引用并保留草稿，网络故障保留任务及结果并支持重新连接。
- App 保留已访问扫描面板的内存状态，隐藏时停止轮询与快照加载并卸载日历弹层；返回恢复草稿、结果分页和同一滚动容器。浏览器刷新只恢复 `wb.scan_run_id` 与 `wb.scan_preferences` 中一份草稿及一份最近提交上下文（含目录默认值合并显式输入得到的有效参数，version=1），重新请求结果；本地存储失败给出提示但不阻断会话。
- 提交冻结当前条件；提交中及活动任务未终止时阻止再创建，允许编辑下一次条件。草稿变化不改变旧结果标签；新结果首屏失败、任务失败或取消时保留旧结果，新快照首屏成功（含零行）才替换。
- 本机提交上下文必须与服务端任务 ID、策略及版本匹配才显示；不匹配或旧任务未保存时说明“原始条件未保存”。结果来源标为本机提交记录，不伪装成服务端完整回显。分页未结束显示“已加载 N 条”，全部加载后显示入选数；所有成功/失败/finally 异步分支隔离旧请求。
- 日期旁说明扫描仅取窗口内最后一根可用主周期 K 线信号，并非区间内全部历史信号。默认日期不强加窗口，优先恢复草稿；未知策略/参数仍显示原 ID。
- 扫描结果定位使用终态响应的 `snapshot_id` 与任务回显的策略/版本，不用“仅按策略查 latest”的模糊路径；结果分页固定首响应的快照 key 续读。
- 金额与价格在 UI 输入以“元”表达，提交前集中换算为缩放 10000 的整数；展示时反向换算；大整数边界由表单校验（初始资金 ≤1e9 元）保证 Number 精度。

## 4. 主要流程

```text
搜索并选择完整证券身份
  → 请求固定版本图表页
  → 展示 K 线、成交量和指标
  → 缩放或平移使可见左缘接近已加载历史左端
  → 自动使用同 data_version + next_before 请求旧页
  → 去重合并并保持视口锚定
```

指标变更会重新发起完整首屏查询，避免把不同指标集合的分页结果混合。

## 5. 交互和可访问性

- 图表头部将证券名称、收藏和最新收盘报价集中左侧，元信息与快照置于下一行；报价组窄屏整体换行。顶部报价采用当前周期/复权/版本最后两根 K 线的收盘差及以前一根收盘为分母的涨跌幅，不随十字光标变化；前收盘缺失或非正时涨跌显示 —，不以开盘价替代。日线与周线分别标注日涨跌、周涨跌。自选报价始终为最新日线原始价格，版本或复权口径不同可能产生差异。
- 顶部报价和图例涨跌红涨绿跌、平盘灰色，保留正负号；OHLC 标签维持灰色，图例涨跌色不得被默认文字规则覆盖。

- 自选列表选中态采用整行蓝灰底（`#192335`）、1px 低透明度蓝色内描边和 10px 圆角，移除左侧竖线；普通行悬停轻微提亮，选中行悬停保持选中底色。背景及描边以 150ms 过渡，不改变行尺寸；减少动态效果偏好下关闭过渡，保留键盘焦点提示和涨跌颜色。

- 搜索输入使用 combobox/listbox 语义，支持上下键、Enter 和 Escape；`/` 全局快捷键聚焦搜索框（输入态除外）。
- 周期和价格视图按钮暴露 `aria-pressed`，弹层和关闭按钮提供明确标签；图表头部 ★ 收藏开关暴露 `aria-pressed`。
- 扫描/回测任务工作区均为顶部条件、下方结果；窄屏条件换行，回测指标两列、表格仅局部横向滚动；范围 chips 与 `RangePicker` 预设按钮暴露 `aria-pressed`；`RangePicker` 弹层为非模态 dialog（打开时聚焦弹层，确定/Escape 关闭后焦点返回触发器，外部点击或页面滚动即收起且不回写未确认的草稿）。
- 移动端（<768px）搜索为顶栏图标触发的全屏浮层，自选面板为抽屉 + 遮罩并保留可操作关闭入口；图表、扫描、回测面板可用性不退化。
- 红涨绿跌是当前产品约定；文字和数值同时表达变化，不只依赖颜色。

## 6. 失败与安全语义

- 非 JSON 或非成功 Envelope 映射为简洁错误，不渲染服务端内部详情。
- 搜索错误清空候选，图表首屏错误进入错误态；分页错误不删除当前结果。
- query 参数在进入状态前白名单校验，不能直接作为 HTML 或请求路径片段。
- 浏览器不保存凭据和数据库信息。

## 7. 性能约束

- 首屏与分页默认 400 根 Bar，指标请求由后端计算预算控制。
- 同类分页同一时间最多一个，新的分页取消旧分页。
- 图表数据合并保持确定排序，避免重复点导致图形抖动。

## 10. 手动保存的看板

- 看板配置持久化在服务端 `t_chart_boards`（单用户全局，无账户体系），经五个 `/api/v1/chart-boards` 接口读写，最多 20 个；不保存行情和凭据。每项有服务端生成的数值 id、name（1–40 字符）与 config；config 字段为 defaultSymbol、timeframe、priceView、indicators（最多16个）、comparison（空或一个现有期货连续品种）、paneWeights 与 visibleBars（10–400，实际设备缩放边界仍生效）。服务端是唯一权威，写路径严格校验并规范化落库，读路径原样透传。
- `useBoards` 异步 API 化并分离已保存快照和草稿。挂载 GET 全量加载；空表首次加载时以默认配置 ∪ URL 参数创建"默认看板"，此后 URL 参数不再种子草稿。新建、保存、另存为、重命名、删除、切换才发起写请求；成功以响应全量替换本地状态并同步草稿（重命名保留草稿），失败保留草稿并显示服务端 message，busy 期间禁用变更操作。最后一个看板不可删除。
- 切股保留当前草稿，不触发未保存标记；默认股票通过显式设置并保存。刷新读取上次激活看板及其默认股票，显式 URL 股票优先；看板控制器挂载于 App（ChartWorkspace 仅在已选证券时挂载，放内部则无股票时永不加载）。切换看板若有修改提供保存并切换/放弃/取消；刷新关闭注册 beforeunload。图表在切工作台页签时隐藏而非卸载，草稿保持内存，不自动持久化。
- 并发语义为操作级最后写入：多标签页各自操作均以响应全量刷新本地，不做跨页冲突检测；空表首载并发建默认看板可能产生两块同名看板（个人工具接受，可重命名/删除清理）。
- 手动保存时同步读取图表的分区权重和观察根数；真实缩放/分区调整标记修改，平移位置不保存。不同参数的副图按完整指标身份隔离，成交量使用独立分区。

## 11. 百分比主图与单关联行情

- 主图 OHLC、MA/EMA 转换为 `(value/baseClose-1)*100`；主标的共用同一基准收盘价。MA5 淡黄 #FDE68A、MA20 蓝 #60A5FA、MA60 紫 #C084FC，均线细线；K线红涨绿跌。图例展示原始价格和基准日期，副图保留原单位。
- 首次窗口最早有效收盘日为无叠加基准；有叠加时选择首次主图窗口内最早共同有效日，两条行情各自使用该日正有限收盘价。基准固定，不随平移和历史分页改变；切股票/周期/复权/关联才重设。无共同日时明确提示，只画股票及其均线。
- 关联下拉仅使用已有八个期货连续序列，油价为 `INE:SC.MAIN`，不扩展股票搜索目录。`queryComparison` 调用现有 `GET market/bars`，version 固定为主图版本，view=raw，limit=5000；达到上限明确提示。日线按UTC日期，周线按ISO周对齐（请求范围扩展至完整周）；缺失点用whitespace，不前填、不零填。
- 关联请求独立取消和重试，失败只影响关联曲线，旧响应不得覆盖当前查询。图表主请求、分页继续遵守既有版本和世代守卫。
- 自选提供名称/代码筛选、用户触发的涨跌幅排序和恢复默认添加顺序；排序以操作时快照固定，更新行情不主动重排。新增股票入口复用顶栏搜索。

## 双价格 Z-score 副图

入口“Z-score 126,5,252”，参数period/smooth/regime/lag，关联选择复用看板既有期货下拉。主请求与分页携带comparison，切换关联会取消旧请求并重新计算。只有日线有效，未选择或失败有独立提示。

## 12. 回测工作台

- App 首次访问后保留回测面板，隐藏时暂停任务轮询、权益/明细资源加载并关闭搜索/日历弹层；恢复时保留草稿、报告、标签页、已加载分页和滚动位置。服务器任务继续运行。刷新从 `wb.backtest_run_id` 和 `wb.backtest_preferences`（version=1）恢复有限元数据，不保存整份结果。存储失败提示，但不阻断当前会话。
- 初始证券沿用当前选择，已有草稿优先；证券名称在已知时显示，搜索选择同时带入名称和手数。草稿不随其他页面选择暗中更改。策略/版本来自目录，参数中文标签复用 `strategyLabels`，未知标签保留 ID；目录失败支持重试。
- 资金使用比例和费率以百分比输入，精确按十进制转换整数 bps；最多两位百分比小数，资金比例0.01–100%、其他费率0–100%。资金/最低佣金仍按元→10000缩放，默认值与校验范围沿用原语义。持有期空/0用策略默认；每手数量及费用折叠、费用摘要常驻。日期直接输入与日历入口共存，不强加初始窗口。
- 草稿、submitted、report分离：提交冻结输入、有效策略参数及实际持有期；提交或任务未终止时禁止重复创建，允许编辑下一轮条件。新任务运行/失败不移除旧报告，并解释下方报告归属。收到成功summary后一次替换报告身份，子组件以run_id隔离，只展示该任务的曲线/明细或各自加载/错误态；不能将旧曲线挂在新指标下。
- 原始条件仅关联任务ID、策略、版本均匹配的本机提交记录；缺失或不匹配明确显示未知，不从当前表单猜测。任务/数据/引擎版本来自服务端，完整条件收进详情。仅保留一份本机提交快照和草稿，不增加历史任务列表。
- 有ID未响应显示恢复中；结构化404 NOT_FOUND只清除对应引用，保留草稿。网络错误不清理引用和报告，连续三次错误停止后支持重连，其他确定性4xx停止自动重试。所有旧请求成功/失败/收尾均不得污染新任务。
- 四个主指标为总收益率、最大回撤、年化收益率、平仓笔数；胜率、盈利因子、平均持有、期末持仓为辅助。null显示—及解释；零平仓不等同无成交，期末持仓注明按最后收盘价计入权益。不计算未提供的基准/夏普/买卖配对盈亏。
- 权益每页1000、最多10页；达到上限仍有游标时明确提示曲线不完整，summary仍是服务端全量汇总。曲线单位元，悬停显示日期、权益、现金、持仓市值；失败可独立重试。
- 成交默认、订单按需加载，每页100，标签切换保留分页；未结束显示已加载N条，结束显示共N条，空记录有独立文案。首屏/续页错误可重试同一页，保留已加载行；暂停或切任务时所有响应隔离。时间/方向/价格/数量/金额优先，ID和费用在详情中；价格最多四位小数、金额两位。订单终态按既有OrderFinalReason稳定枚举显示中文原因，未知值明确保留编号。

## 数据更新面板

顶栏 RefreshMonitor 入口展示股票或期货运行状态，非模态面板展示两类进度、分页历史和固定任务的失败明细。仅股票提供手动按钮；来源、成功/失败/待完成、已用时间、最近进展和记录时间均有文字说明。没有更新对象、准备中、全部成功、部分成功、失败和中断分开展示，不估算剩余时间。

可见且运行中每5秒查询，收起或无活动任务每30秒；隐藏暂停并取消查询，恢复可见立即查，旧响应不能覆盖当前状态。终态详情停止轮询，顶栏继续发现后续任务。失联保留最后记录，超60秒心跳仅提示状态待确认；过期记录允许显式触发，由服务端 guard 防重。提交失败先查询，不自动重发 POST。关闭面板不取消更新。历史从服务端恢复，界面不保存执行断点。

完成后“加载最新行情”由用户主动重载图表和自选报价，后台不自动改变固定图表版本。自选刷新文案改为刷新报价，仍仅查询已有行情。Escape关闭并归还入口焦点，进度有可访问标签，手机布局单列。
