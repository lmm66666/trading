# 指标模块设计

| 属性 | 内容 |
|---|---|
| 状态 | 当前有效 |
| 适用范围 | `internal/indicator` |
| 最后更新 | 2026-09-14 |

## 1. 职责与非职责

本模块在固定行情 Dataset 上构建带有效位的指标序列，也为调用方已经对齐的数值序列提供纯计算函数，统一描述预热和无效值传播。目前支持 OHLC、SMA、EMA、STD（总体标准差）、成交量均线、MACD、KDJ 和相对价格滚动 Z-Score。

本模块不读取数据库、不请求行情、不选择数据版本、不决定策略信号，也不将预热期无效值替换为零。

## 2. 对外能力与使用者

- `Ref` 完整标识指标种类、周期、价格视图、字段和参数；`Key` 为相同引用生成跨运行稳定键。
- `Series` 保存数值与逐点有效位，通过 `At`、`Valid`、`Slice` 提供防越界读取。
- `BuildContext` 对一组引用去重计算并返回 `Set`，在指标边界响应 context 取消。
- `STDKind` 引用支持 OHLC 字段与正周期，计算完整滚动窗口总体标准差；使用中心化两遍计算，预热/无效窗口不输出，常量窗口有效值为0。图表使用 Close 字段、周期上限500和成本预算。
- `SMA`、`EMA` 提供基础序列计算；复合指标由构建图内部组合。
- `RelativePriceZScore` 对两条由调用方按日线时点对齐的正价格序列计算对数价格比的滚动总体标准化结果，不接入单 Dataset 的 `Ref` 和构建图。

应用层、策略 Registry、Replay 和图表查询使用指标集合。

## 3. 依赖和边界

只依赖 `internal/market` 和 Go 标准库。输入 Dataset 必须先通过行情领域校验；复权价格只能使用同行情版本的有效因子。

指标引用是策略定义与运行时特征集合之间的契约。引用规则改变可能影响策略语义，必须同步评估策略版本。

## 4. 核心模型与不变量

- 每个 `Series` 的 values 与 valid 长度相同，长度与输入 Dataset 一致。
- 越界、预热不足或依赖点无效时返回无效，不产生可参与策略判断的伪值。
- SMA、EMA、STD、MACD、KDJ 只使用当前点及历史点；在序列末尾追加未来 Bar 不得改变既有前缀。
- `Ref.Validate` 拒绝未知种类/字段、非法周期、MACD `slow <= fast`、不匹配参数和成交量复权视图。
- 合法 `Ref.Key` 唯一包含所有影响计算的参数；非法引用的键为空。
- 同一 Build 请求中的重复引用只计算一次，返回集合按稳定键索引。
- 相对价格价差为 `ln(primary)-ln(comparison)`，滚动 Z-Score 使用总体标准差；输出与输入等长，预热不足或窗口标准差不大于 `1e-12` 时对应点无效。
- 相对价格函数要求输入等长、周期至少为 2 且所有价格为正有限数；周期大于输入长度只表示尚未预热。函数只读输入，不检验相关性、协整或均值回归。

## 5. 主要流程

```text
已校验 Dataset + 同版本复权因子 + Ref 集合
  → 校验并规范化引用
  → 按稳定 Key 去重
  → 构建价格/成交量基础序列
  → 计算派生指标并传播有效位
  → 返回 Set
```

图表页在完整历史上下文中计算指标后再裁剪响应，从而保持分页边界连续；该裁剪由应用层负责。

相对价格计算的独立流程为：

```text
调用方已对齐的两条日线价格序列
  → 校验长度、周期和价格
  → 计算逐点对数价格比
  → 计算完整滚动窗口的均值与总体标准差
  → 输出带预热和零方差无效位的 Z-Score Series
```

## 6. 失败、取消和一致性语义

- 任一引用非法、Dataset 不兼容或复权因子不足时，整个 Build 返回错误，不发布部分特征图。
- `BuildContext` 在开始和计算边界检查取消；取消错误原样传播。
- 计算失败带引用上下文包装，同时保留底层原因。
- 相对价格输入长度不一致、周期小于 2、价格非正或非有限时返回可识别的输入错误；日期未对齐属于调用方违反前置条件，裸价格切片无法自行识别。

## 7. 性能与安全约束

- 计算复杂度应随 Bar 数和唯一引用数有界增长，重复引用不得重复计算。
- 相对价格函数不得修改调用方切片；追加未来值不得改变已有前缀结果。
- API 必须在调用前限制引用数、周期和总计算预算；本模块仍独立拒绝非法参数。
- 浮点只用于指标计算，持久化 Price/Money 的定点语义不因此改变。

## 8. 测试与验收证据

测试覆盖引用完整校验、稳定键、预热有效位、取消、重复引用去重、复合指标、相对价格总体标准差与输入失败语义，以及所有内置指标的前缀不变性。

```bash
go test ./internal/indicator -cover
```

覆盖率门槛为 90%。
