# 回测模块设计

| 属性 | 内容 |
|---|---|
| 状态 | 当前有效 |
| 适用范围 | `internal/backtest` |
| 最后更新 | 2026-09-14 |

## 1. 职责与非职责

本模块提供确定性、单证券、纯多头、现金账户的回测引擎，包括账户、订单、成交、费用、滑点、公司行动、持仓、权益曲线和绩效指标。

本模块不读取或写入仓储、不创建持久化任务、不选择行情版本、不并行回放证券，也不模拟当前模型没有明确表达的交易所微观结构。

## 2. 对外能力与使用者

- `Config` 描述初始资金、仓位比例、佣金、最低佣金、印花税、过户费、滑点、手数和持有期。
- `ExecutionModel` 在 Bar 开盘和涨跌停/停牌约束下决定成交或稳定拒绝原因。
- `Account` 原子应用成交与公司行动，并提供防御性持仓视图。
- `Engine.Run` 串行推进 Timeline，返回订单、成交、闭合交易、权益、最终持仓和 Summary。
- 指标计算提供收益率、年化、最大回撤、胜率、盈亏比和平均持有 Bar 等结果。

应用层回测服务负责加载输入、持久化结果和任务生命周期。

## 3. 依赖和边界

只依赖 `internal/market`、`internal/strategy` 和 Go 标准库。输入必须是同一证券、同一正数据版本的合法 Timeline 与公司行动集合。

费用和撮合配置属于可复现输入；应用层必须把完整配置纳入任务摘要。任何撮合、成本或引擎时间线语义变化必须提升 `EngineVersion`。

## 4. 核心模型与不变量

### 4.1 配置与金额

- Money/Price 使用缩放 10000 的整数，费率使用 0–10000 bps。
- `CashFractionBPS` 为 1–10000，LotSize 为正，费用和持有期非负。
- 所有乘除、费用、持仓价值和现金变化检查溢出；成本按确定的向上/向下取整规则计算。

### 4.2 时间线和成交

每根 Bar 的固定顺序为：

1. 应用开盘前公司行动。
2. 尝试执行上一根收盘后生成的挂单。
3. 应用 Bar 内、收盘前公司行动。
4. 按收盘价计算权益。
5. 向策略暴露只含当前及历史值的 Context。
6. 把策略决策转换为最早下一根开盘可执行的订单。

信号 Bar 绝不成交。末根 Bar 产生的订单保留为“无下一根 Bar”，不能回填到同一 Bar。

### 4.3 账户和订单

- 买入按现金比例和手数向下取整，不允许现金变负；卖出不超过现有持仓。
- 成交 ID/订单 ID 具有幂等含义，同一成交不能重复改变账户。
- 买入拒绝在下一次策略决策后失效；退出因不可交易被拒绝时可在后续 Bar 重试，直至成功或数据结束。
- `HoldBars=0` 使用策略默认值；策略也未定义时使用引擎缺省 10 根。入场 Bar 计为持有第 1 根。
- 显式退出与默认持有期退出不能生成重复订单。

### 4.4 公司行动和指标

- 公司行动按证券、数据版本、稳定 ID 和发生时间校验，重复或无法落入 Timeline 的行动使输入失败。
- 现金分红计入现金及闭合交易收益；送股改变数量和成本基础，不伪装为现金收益。
- 一批公司行动要么全部应用，要么账户保持不变。
- 未闭合持仓不进入胜率等闭合交易比率；无定义比例返回空值，不返回 NaN 或无穷。

## 5. 主要流程

```text
完整 Input 预校验
  → 建立独立账户与撮合模型
  → 严格按 Timeline 串行推进
  → 订单在下一开盘尝试成交
  → 收盘逐点估值
  → 生成不可变 Result 与 Summary
```

预热 Bar 只用于上游构造指标；应用层把回测账户和对外结果窗口限制在请求起点。

## 6. 失败、取消和一致性语义

- 输入、策略定义、特征、公司行动或配置非法时，在产生账户副作用前失败。
- 账户与公司行动先预计算完整变化，任何验证或溢出错误均不部分修改状态。
- `Engine.Run` 在 Bar 和关键计算边界检查 context；取消返回错误和空结果，不发布部分成功。
- 正常不可成交由 `RejectReason` 和订单最终原因表达，不作为引擎异常。

## 7. 性能与安全约束

- 引擎单线程、按 Bar 线性执行；一个 Engine 值无可变字段，可并发用于相互独立的输入。
- 不使用浮点持久化金额，不接受负现金、超量卖出或算术溢出。
- Timeline 和账户视图不得向策略暴露可修改的内部 map/slice。

## 8. 测试与验收证据

测试覆盖下一 Bar 成交、停牌/涨跌停、费用与滑点、手数、拒绝重试、默认持有期、公司行动原子性、溢出、取消、禁止未来数据、权益和指标边界。

```bash
go test ./internal/backtest -cover
```

覆盖率门槛为 90%。
